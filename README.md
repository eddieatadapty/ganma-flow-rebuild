# GANMA! Growth Audit

**Live → https://eddieatadapty.github.io/ganma-flow-rebuild/**

Five ideas to turn more GANMA! users into subscribers, each built into a clickable version of GANMA!'s own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Chapter 1 before anything else | +10–15% CR to purchase |
| 02 | One question, already answered by the ad | +8–15% CR to purchase |
| 03 | Sell 先読み where the wait is felt | +10–20% CR to purchase |
| 04 | Proof and the free trial beside the button | +10–15% CR to purchase |
| 05 | Catch the people who close the paywall | +5–10% ARPU |

Every price, rating and feature comes from GANMA!'s App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for GANMA!. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
